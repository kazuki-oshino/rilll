# Research Report

このセクションは、エージェントが直前の調査作業 (技術調査 / 仕様調査 / 影響範囲調査等) で得た知見を、後段の意思決定ステップが機械的に処理しやすい形に整形して書き出すための構造化テンプレートである。

以下のルールを守ってこのテンプレートを埋めること:

- 見出し (`## Question` / `## Findings` / `## Sources` / `## Recommendations` / `## Open Questions`) と順序は改変しない。
- 各見出し直下では、本テンプレートの説明文 (この `<...>` を含む行) を削除し、実際の内容で置き換える。
- `## Findings` の各項目は 1 件 1 行で書き、末尾に `## Sources` セクションの `[S1]` / `[S2]` 形式 ID を 1 個以上付与して根拠を必ず外部参照に紐付ける。複数あれば `[S1], [S3]` のようにカンマ区切り。
- `## Sources` には Findings で参照した ID をすべて記載する。`[Sn]: <URL またはローカルパス + 行番号 等>` 形式で、Findings で言及していない source は載せない。
- `## Recommendations` の各項目は行頭マーカ + 命令形 1 行で書き、根拠となる `[Sn]` ID を末尾に付与する。
- 推測ではなく Phase 1 で観測 / 検証した事実のみを `## Findings` に書く。確認できていない事項は `## Open Questions` に逃がす。

## Question

調査の起点となった問いを 1-3 文で書く。スコープ (調査対象 / 除外範囲) と、回答の用途 (どの後段判断に使われるか) を含める。

- <調査対象: 何を / どの範囲で調べたか>
- <用途: 回答がどの判断 / 設計選択に使われるか>

## Findings

調査で観測した事実を、回答上の重要度 (Question への寄与度) が高い順に列挙する。各行は事実記述 + 根拠 ID で構成する。

- <Finding 1: 1-2 文の事実記述。「何が / どの条件下で / どう振る舞うか」を含める> [S1]
- <Finding 2: 同上> [S2]
- <Finding 3: 同上> [S1], [S3]

## Sources

Findings で参照した出典を一覧化する。

- [S1]: <URL またはローカルパス + 行番号 / 行範囲。例: `internal/agent/agent.go:129-227` / `https://example.com/spec#section-3`>
- [S2]: <...>

## Recommendations

Findings に基づいて取るべき次のアクションを、優先度 (上が高) の順に列挙する。各行は命令形 1 行 + 根拠 ID で構成する。該当事項が無ければ `- なし` の 1 行だけを書く。

- <推奨アクション 1: 何を / どの対象に / 何のために実行するか> [S1]
- <推奨アクション 2> [S2]

## Open Questions

調査中に解消できず、`## Findings` に載せられなかった事項を列挙する。無ければ `- なし` の 1 行だけを書く。

- <疑問 1: 確認したい点 / 想定される選択肢 / 影響範囲>
